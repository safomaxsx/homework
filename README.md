# Интерактивные ДЗ

`index.html` — движок, который один раз загружается на GitHub. Каждое ДЗ — отдельный файл `hw/ИМЯ.json`.
Ссылка для ученика: `https://safomaxsx.github.io/homework/?hw=ИМЯ`

## Запуск (один раз, ~5 минут)
1. github.com → **New repository** → имя `homework`, тип **Public** → Create.
2. **Add file → Upload files** → перетащи `index.html`, `README.md`, `PROMPT.md` и папку `hw` → **Commit changes**.
3. **Settings → Pages** → Source: *Deploy from a branch*, Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сайт заработает: `https://safomaxsx.github.io/homework/?hw=demo-lesson`

## Новое ДЗ
1. В чате ученика вставь промпт из `PROMPT.md` и получи JSON-файл.
2. В репозитории открой папку `hw` → **Add file → Upload files** → перетащи файл → Commit.
3. Через 1–2 минуты ссылка работает. Обязательно открой её сам: если в файле ошибка, страница покажет красный блок с описанием.

Исправить ДЗ: открой файл в `hw/` → значок карандаша → Commit. Если ученик уже начал выполнять, добавь в JSON `"version": 2`, чтобы у него сбросился сохранённый прогресс.

## Как это работает для ученика
- Ответы сохраняются в его браузере: можно закрыть страницу и вернуться позже.
- После «Проверить раздел» раздел закрывается, появляются ответы, пояснения и баллы.
- В конце: «Скопировать отчёт» или «Отправить в Telegram». В отчёте баллы, все ошибки и тексты письменных заданий.

## Ограничения
- Репозиторий публичный: в файлах только имя ученика, без фамилий и контактов.
- Ответы лежат внутри JSON-файла, и продвинутый ученик теоретически может их подсмотреть.
- GitHub Pages: сайт до 1 ГБ и около 100 ГБ трафика в месяц. Одно ДЗ весит примерно 5–15 КБ, так что хватит на десятки тысяч.
- Аудио нельзя хранить в репозитории, если файлы тяжёлые. Лучше давать прямую ссылку на mp3 в поле `audio`.
