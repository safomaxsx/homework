# Промпт: интерактивное ДЗ (вставлять в чат ученика)

Скопируй всё, что ниже линии, в чат ученика и заполни блок «ДАННЫЕ».

---

Сделай интерактивное домашнее задание по английскому в виде **одного JSON-файла** для моего движка ДЗ (GitHub Pages). Используй всё, что знаешь об этом ученике из чата: уровень, цель, пройденные темы, типичные ошибки.

## ДАННЫЕ
- Ученик (как подписать на странице): …
- Режим: урок / экзамен (ЕГЭ, ОГЭ, МЦКО, SCIO, олимпиада: …)
- Последний урок (темы, лексика, грамматика): …
- Следующий урок (к чему подготовить): …
- Что повторить (старые темы и ошибки): …
- Объём: примерно … минут
- Сдать до: …
- Пожелания (письмо или устная часть нужны? таймер?): …

## КАК СОСТАВИТЬ
1. Примерно 70% заданий — по последнему уроку, 20% — повторение старых тем и ошибок, 10% — подводка к следующему уроку.
2. Разделы идут от простого к сложному: лексика → грамматика → текст → продуктивное задание.
3. В режиме экзамена задания строго в формате экзамена: актуальные номера, формулировки инструкций, объёмы слов. Номера ставь через `start` и `label`. Формат и номера проверяй по актуальной демоверсии (ФИПИ для ЕГЭ и ОГЭ), не по памяти. Если блок сокращён, пиши в label «(фрагмент)».
4. Тексты и предложения пиши сам, без копирования из учебников и КИМ.
5. Инструкции и пояснения пиши по-русски (на C1+ можно по-английски). Пояснение объясняет правило, а не просто повторяет ответ.
6. В пропусках `gap` перечисли **все** допустимые варианты ответа, включая сокращения: `["have never been", "'ve never been"]`. Регистр, пробелы и финальная точка не важны.
7. В `choice` и `select` должен быть ровно один бесспорно верный вариант. Дистракторы правдоподобные, но однозначно неверные. Проверь каждый вариант на двусмысленность.
8. Перед выдачей перепроверь: число `{}` в `q` = длина `answers` (и `hints`, `options` у select). Индексы ответов считаются **с 0**. JSON валиден: двойные кавычки, без комментариев и висячих запятых.

## ФОРМАТ ВЫДАЧИ
- Имя файла: `имя-латиницей-ГГГГ-ММ-ДД.json` (например `artem-2026-11-20.json`). Это же значение запиши в поле `id`.
- Выдай файл целиком, а в конце дай ссылку: `https://safomaxsx.github.io/homework/?hw=ID`.
- В JSON только имя ученика, без фамилии и личных данных: файлы в репозитории публичные.

## СХЕМА
```json
{
  "id": "artem-2026-11-20",
  "title": "Заголовок ДЗ",
  "student": "Артём",
  "exam": "ЕГЭ по английскому",
  "level": "C1",
  "topic": "Тема",
  "due": "27.11.2026",
  "timeLimit": 60,
  "intro": "Текст приветствия. **жирный**, *курсив*, пустая строка = новый абзац",
  "sections": [
    {
      "title": "Название раздела",
      "label": "Задания 19–24",
      "instructions": "Что делать",
      "text": "Необязательный текст для чтения",
      "audio": "Необязательная ссылка на mp3",
      "tasks": [ ]
    }
  ]
}
```
Необязательные поля можно не писать: `exam`, `timeLimit` (в минутах), `label`, `text`, `audio`, `image`, `due`, `level`, `topic`.

## ТИПЫ ЗАДАНИЙ (`tasks`)

**choice**: выбор одного ответа. Если `answer` — массив, ученик выбирает несколько вариантов.
```json
{"type":"choice","num":12,"q":"Вопрос","options":["A","B","C","D"],"answer":2,"explain":"Почему"}
```

**gap**: впиши слово. `{}` = пропуск. `hints` — слово-подсказка справа от пропуска (как в ЕГЭ 19–29). `start` — номер первого пропуска.
```json
{"type":"gap","start":19,"q":"She {} home.\nThey {} late.","hints":["GO","BE"],"answers":[["went"],["were"]],"explains":["…","…"]}
```

**select**: выпадающий список в пропуске (как в ЕГЭ 30–36).
```json
{"type":"select","start":30,"q":"He decided to {} part.","options":[["make","take","do","have"]],"answers":[1],"explains":["take part in"]}
```

**match**: соотнесение (заголовки, определения, говорящие). Лишние варианты допустимы. Длинные варианты показываются нумерованным списком.
```json
{"type":"match","items":["Текст A","Текст B"],"options":["Заголовок 1","Заголовок 2","Лишний"],"answers":[1,0],"explain":"…"}
```

**tf**: True / False / Not stated (по умолчанию). Подписи можно сменить через `labels`, например `["Верно","Неверно"]`.
```json
{"type":"tf","start":2,"statements":["…","…"],"answers":[0,2],"explains":["…","…"]}
```

**order**: собрать предложение из частей. В `items` части стоят **в правильном порядке**, движок перемешает их сам.
```json
{"type":"order","q":"Собери вопрос:","items":["Have","you","ever","been","to","London?"],"explain":"…"}
```

**write**: письменный ответ со счётчиком слов. Не оценивается автоматически: после проверки ученик видит чек-лист и образец, а текст попадает в отчёт для учителя.
```json
{"type":"write","q":"Задание","min":100,"max":140,"criteria":["К1: …","К2: …"],"model":"Образец ответа"}
```

**speak**: устное задание с таймерами подготовки и ответа (в секундах). Ученик отправляет голосовое.
```json
{"type":"speak","q":"Задание","prep":90,"time":120,"note":"Запиши голосовое","model":"Образец (необязательно)"}
```

`points` (необязательно) — сколько баллов стоит задание choice или order. По умолчанию 1. В gap, select, match и tf каждый пропуск стоит 1 балл.
